🚀 PRÓXIMOS PASOS - PARA EMPEZAR
═════════════════════════════════════════════════════════════════════════════

1. LEE: INSTALACION_RAPIDA.md (5 minutos de lectura)

2. INSTALA:
   • Node.js: https://nodejs.org
   • PostgreSQL: https://www.postgresql.org

3. CONFIGURA:
   • BD: createdb ictue_db
   • Schema: Importar 001_init.sql
   • .env: Completar rutas y secretos

4. INICIA:
   • Backend: npm run dev (puerto 5000)
   • Frontend: npm run dev (puerto 3000)

5. ABRE: http://localhost:3000

6. IMPORTA DATOS (opcional):
   • python data/import_data.py

📊 ESTRUCTURA DE BASE DE DATOS
═════════════════════════════════════════════════════════════════════════════

TABLA: usuarios
  ├── id (PK)
  ├── email (UNIQUE)
  ├── nombre
  ├── rol (pastor, lider)
  ├── password_hash
  └── created_at, updated_at

TABLA: reuniones_planeadas
  ├── id (PK)
  ├── dia_semana (MAR, JUE, DOM)
  ├── hora
  ├── tipo_reunion (Culto, UNT Kids, UNT Teens)
  ├── seccion (1 o 2)
  └── descripcion

TABLA: asistencia (el core)
  ├── id (PK)
  ├── reunion_id (FK)
  ├── fecha
  ├── num_asistentes
  ├── expositor
  ├── observaciones
  ├── registrado_por (FK)
  └── created_at, updated_at
